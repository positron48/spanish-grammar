# Самостоятельная диагностика ES → RU

Банк проверяет практическое понимание грамматики в коротком контексте. Для ответа не нужны теория курса, названия времён или авторские обозначения. Уровни взяты из `../config/generation-status.json`, главы используются для рекомендаций после теста.

## Матрица

| Уровень | 8 умений, по 10 заданий на каждое |
| --- | --- |
| A1 | согласование; артикли; указание на предмет; представление; вопросы; существование/местоположение; владение/состояния; повседневные действия |
| A2 | неправильные и возвратные глаголы; предпочтения и действие сейчас; опыт/результат; законченные события; фон/привычки прошлого; планы/предположения; возможность/обязанность; инструкции |
| B1 | количество; сравнение; цели/причины/направления; устойчивые предлоги; передача предметов; действия с se; связи между мыслями; уточнение человека/места/вопроса |
| B2 | развитие и прекращение действия; временная последовательность; желания/эмоции; сомнение/уверенность; будущие условия времени/цели; поиск/уступка; гипотеза сейчас; несостоявшееся прошлое |
| C1 | пассив/безличное сообщение; точность пересказа; передача просьб; источник/степень достоверности; логика аргумента; информационный фокус; сжатие формулировки; регистр/тактичность |

## Редакционные правила

1. Ситуация и цель задания полностью видны на карточке; русский текст простой, испанский естественный.
2. Один основной skill и один однозначный ответ. Варианты могут быть грамматически верны, но обязаны различаться по требуемому смыслу.
3. Контекст не требует знакомства с курсом или специализированных знаний. В заданиях на интерпретацию русский ответ проверяет понимание испанского сообщения.
4. Не противопоставляем допустимые региональные нормы: perfecto/indefinido не оцениваются как «правильно/неправильно» лишь по маркеру hoy; не используем leísmo, vosotros/voseo и конкурирующие формы -ra/-se как ловушки.
5. Смена имени или числа не образует новое семейство. Каждый сюжет самостоятелен; `family_id` фиксирует именно сценарий. При добавлении узнаваемых переработок сохраняем его.
6. Difficulty — редакционная сложность внутри уровня (1/2/3), не психометрическая оценка. На каждом уровне 24/32/24 вопроса соответствующей сложности; калибровка ожидает пилота.
7. Утверждение `approved` означает завершённую авторскую проверку текста, ключа и привязки. Независимое внутреннее ревью, внешняя лингвистическая проверка и пользовательский пилот учитываются отдельно в `review/status.json`.
8. Формулировки верхних уровней проверяют смысл, точность пересказа, связь и регистр, а не трудность русской инструкции.

Вопросы хранятся только в `items/`, по 10 на навык. Стабильные идентификаторы не перенумеровываются при редактуре; изменение задания увеличивает `revision`. В production выдаются только публичные поля; ключ и объяснение остаются на сервере до окончания попытки.

Исследование распределения и ограничений: `docs/placement/ES_RESEARCH.md` в основном репозитории. Общие схема, blueprint и сборка поддерживаются основным приложением. Этот банк не является сертификационным тестом общего владения языком.

Итог внутреннего независимого обзора — passed; подробности в `docs/placement/ES_INDEPENDENT_REVIEW.md` основного репозитория.
